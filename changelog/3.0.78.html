v3.0.78: Virtual Button pages for external VMS embedding - each virtual-button widget can mint a no-login page URL (plain HTTP, token-secured) for use as a Web Page object in NX Witness and similar consoles; buttons look and behave exactly like the dashboard widget, with per-button token rotation and a whole-page revoke. Alert Manager manual device registration is restored (adding another siren failed in 3.0.77). The video codec indicator and playback routing now follow the stream actually being played, not the camera's main track. Manual RTSP camera add no longer freezes silently at Adding... (defect present since 3.0.63); the dialog reports failures and times out honestly. The default update endpoint moved to the ICLab Technologies organization; the previous endpoint is served again for existing installations. Images are published to ghcr.io/iclabtech and the previous registry namespace. This release adds two database tables and two columns; existing cameras, zones, users and recordings are preserved. Multi-arch amd64 and arm64. Recommended upgrade: apply the online update or re-run the installer package.
